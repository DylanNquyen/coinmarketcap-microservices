Architecture Decision Records (ADRs) preserve the context and consequences of decisions that are costly to reverse.

## Adding an ADR

Copy `0000-template.md`, assign the next number, and keep the document concise. Accepted ADRs are immutable; supersede an old decision with a new ADR instead of rewriting history.
